# Правила стола

Стол работает сам: хозяина нет, раунды начинаются автоматически.

## Жизненный цикл

```text
waiting ──(кто-то сел)──▶ betting (10 c) ──(все готовы | время вышло)──▶ player ──▶ dealer ──▶ over
   ▲                          ▲                                                                  │
   └──(нет игроков)───────────┴────────────────(пауза 5 c)──────────────────────────────────────┘
```

1. **Приём ставок.** Как только за столом есть игрок, открывается окно ставок на 10 секунд. Ставка по умолчанию — 0.
2. **Готовность.** Игрок нажимает «Готов». Раунд начинается, когда готовы все подключённые игроки, даже если окно ещё не закончилось. Если кто-то не успел — раунд начнётся по истечении 10 секунд.
3. **Игра.** Ставки списываются, карты раздаются только тем, у кого ставка больше нуля. Остальные просто смотрят раунд.
4. **Дилер.** Открывает закрытую карту и добирает с задержкой.
5. **Расчёт.** Результаты показываются на 5 секунд, затем снова открывается приём ставок, а ставки и готовность сбрасываются в 0.
6. **Пустой стол.** Если за столом не осталось игроков, он ждёт 5 минут и удаляется.

## Правила игры

| Правило | Значение |
| --- | --- |
| Колода | шуз из 6 колод; пересобирается, когда карт не хватает |
| Блэкджек | 3:2, только первые две карты; после сплита 21 платит 1:1 |
| Дилер | добирает до 17, мягкая 17 — стоп |
| Удвоение | только на двух картах, разрешено после сплита |
| Сплит | только пара одинаковых рангов, повторный сплит недоступен |
| Ставка | целое число от 0 до текущего баланса; 0 — пропуск раунда |
| Баланс | 1000 фишек при посадке |
| Докупка | только если на балансе 0 фишек |
| Время на ход | 60 секунд, затем авто-пас |
| Максимум игроков | 6 |

## Выплаты

| Итог | Выплата |
| --- | --- |
| Блэкджек | ставка + половина ставки (округление вниз) |
| Победа | 2 × ставка |
| Ничья | возврат ставки |
| Поражение / перебор | 0 |

Фишки всегда целые: при нечётной ставке половина фишки округляется в пользу стола.

## Что не поддерживается

- страховка и «равные деньги»
- сдача (surrender)
- повторный сплит (re-split)
- сплит разных 10-очковых карт (например, 10 и K)
